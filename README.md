# Noor Web Solutions - Professional React + Vite + Tailwind CSS Website

## Features
- Attractive responsive professional freelance developer website
- WhatsApp integrated contact form (messages go directly to +91 8618639371)
- Project photos in Services & Portfolio sections
- Coding videos section with YouTube embeds + live code visual
- Typing animation in hero section
- Navbar with smooth section routing
- Tailwind CSS v4 via @tailwindcss/vite
- SEO meta title, description, keywords, canonical and Schema.org
- Local SEO sections for Purnea/Purnia, Araria, Kishanganj, Bhagalpur, Katihar, Darbhanga and Patna
- Project portfolio, services, process, FAQ and enquiry form

## Contact Form Integration
Form data is sent via WhatsApp to **+91 8618639371**.  
When a client submits the form, WhatsApp opens with a pre-filled professional message containing Name, Email, Phone, Project Type and Details.

## Run
1. Install Node.js
2. Open this project folder
3. Run: `npm install`
4. Run: `npm run dev`
5. Open the URL shown by Vite (usually http://localhost:5173)

## Build
`npm run build`

## Important
Replace the canonical URL in index.html after connecting your real domain.
